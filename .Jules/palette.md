## 2025-05-18 - Mobile Menu Icon Button Accessibility
**Learning:** Icon-only interactive elements (like the mobile hamburger menu button) often lack `aria-label`s, which causes screen readers to either ignore them or read out unhelpful information. Furthermore, hiding default focus rings using `focus:outline-none` on such components creates keyboard navigation issues, as it removes visual feedback for keyboard users.
**Action:** When creating or updating icon-only buttons, always ensure they have an `aria-label` describing the action, set `aria-hidden="true"` on the icon itself, and replace `focus:outline-none` with `focus-visible:ring-2` (and an appropriate ring color) to maintain accessibility while satisfying design requirements. In addition, when these buttons control the visibility of another element, maintain accurate `aria-controls` and `aria-expanded` attributes using JavaScript.
