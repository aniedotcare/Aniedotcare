## 2024-05-18 - [Accessible Mobile Menu Button]
**Learning:** Icon-only interactive elements without ARIA attributes or visible focus states create significant accessibility barriers, especially for screen reader and keyboard users. Additionally, relying solely on CSS classes (like `hidden`) without updating corresponding ARIA states (like `aria-expanded`) leaves assistive technology uninformed about dynamic changes.
**Action:** When implementing or updating mobile menus or similar toggles, always include descriptive `aria-label` and `aria-controls` attributes, actively manage the `aria-expanded` state via JavaScript in tandem with visual changes, use `aria-hidden="true"` on decorative internal icons, and replace `focus:outline-none` with accessible alternatives like `focus-visible:ring-2` to preserve visual focus indicators specifically for keyboard navigation.
