## 2023-10-27 - [Menu Button A11y]
**Learning:** Adding `aria-expanded` and `aria-controls` to toggle buttons improves screen reader accessibility. Ensure JavaScript updates `aria-expanded` state dynamically when the menu visibility changes. Use `focus-visible` to give keyboard users clear focus outlines instead of plain `focus:outline-none`.
**Action:** Apply `aria-label`, `aria-expanded`, and `aria-controls` to icon-only toggle buttons and link them dynamically via JS. Ensure `focus-visible` classes are in place for keyboard navigation.
