## 2024-06-28 - Mobile Menu Button Accessibility Focus Indicators
**Learning:** For interactive elements like mobile menu buttons, the common Tailwind pattern of using `focus:outline-none` creates an accessibility issue for keyboard users who lose the visual focus indicator. Using `focus-visible` classes (like `focus-visible:ring-2 focus-visible:ring-sage`) provides necessary visual feedback specifically for keyboard navigation without affecting mouse clicks. Additionally, ensuring proper ARIA attributes (`aria-expanded`, `aria-controls`, `aria-label`) dynamically updates screen readers about the menu's state.
**Action:** When adding or auditing custom buttons that hide the default focus outline, always ensure an alternative visual indicator is provided using `focus-visible` classes. Also, tie visibility state changes in JavaScript to dynamic updates of `aria-expanded`.
